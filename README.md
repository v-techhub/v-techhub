## About Me

I'm a software developer focused on building modern web applications, intuitive interfaces, and dependable software systems.

I care about more than making things work. I enjoy thinking through how products should feel, how applications should be structured, how data flows across systems, and how to turn complex requirements into simple, usable experiences.

My primary focus is frontend engineering, with hands-on experience across backend development, APIs, databases, mobile applications, integrations, and deployment.

- 🖥️ Building modern web experiences with React, Next.js, and TypeScript.
- 📱 Developing cross-platform applications with React Native.
- ⚙️ Designing backend services, REST APIs, and application architecture with Node.js.
- 🗄️ Working with databases, integrations, authentication, and data-driven applications.
- ☁️ Deploying, maintaining, and troubleshooting applications across different environments.
- 🧠 Interested in software architecture, performance, developer experience, and building products that solve meaningful problems.

I enjoy taking ideas from requirements and planning through development, deployment, and continuous improvement.
